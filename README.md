# Классификация уровней ожирения

Исследование методов классификации уровня ожирения по антропометрическим данным, пищевым привычкам и образу жизни. Работа выполнена в ноутбуке [`research.ipynb`](research.ipynb).

## Выбор датасета

Использован датасет **Obesity Levels**, содержащий 2 111 наблюдений, 16 признаков и целевую переменную с 7 упорядоченными классами — от недостаточного веса до ожирения III типа.

Датасет выбран по следующим причинам:

- в данных одновременно присутствуют числовые и категориальные признаки;
- можно сравнить обычную классификацию с регрессией по порядковым меткам;
- относильно небольшой объём данных.

В данных нет пропусков; обнаружено 24 полных дубликата. Классы распределены достаточно равномерно.

## Гипотезы до начала работы

1. Деревья решений и их ансамбли будут лучше решать задачу многоклассовой классификации, чем линейные модели.
2. Из-за небольшого объёма данных и семи классов дерево начнёт заметно переобучаться при глубине больше 5.
4. Вес (`Weight`) будет сильно коррелировать с признаками образа жизни `FAF`, `SMOKE`, `SCC`, `NCP`, `FCVC` и `FAVC`.
5. Рост (`Height`) и вес (`Weight`) будут вносить основной вклад в предсказание целевого класса.
6. Регрессия по порядковым меткам с последующим подбором порогов будет работать лучше обычной многоклассовой классификации.

## Краткие результаты

1. Деревья будут лучше решать задачу многоклассовой классификации — гипотеза подтвердилась. Ансамбли деревьев показали лучшие результаты: F1 macro составила 0,952 для Random Forest и 0,981 для HistGradientBoosting, тогда как у многоклассовой логистической регрессии — 0,890.
2. Из-за небольшого количества данных и большого числа классов деревья будут переобучаться при глубине больше 5 — пока не подтверждена.
3.  Weight сильно коррелирует с FAF, SMOKE, SCC, NCP, FCVC и FAVC — гипотеза не подтверждена.
    Наличие связи привычек с весом не означает сильную корреляцию в конкретном датасете. Для ответа нужны коэффициенты корреляции для каждой перечисленной пары; одного графика важности признаков недостаточно. При этом слабая корреляция не исключает нелинейную зависимость. В исправленный ноутбук добавлена отдельная проверка этих связей, но её результаты ещё необходимо получить.
4.  Комбинация Height и Weight вносит основной вклад в предсказание.
5.  Регрессия с порогами будет лучше обычной многоклассовой классификации благодаря упорядоченности классов — преимущество не подтверждено.
    В исходном запуске тестовый F1 macro составил около 0,861 для OLS с порогами и 0,865 для Ridge с порогами, против 0,890 у многоклассовой логистической регрессии. Упорядоченность классов делает такой подход осмысленным, но не гарантирует превосходство.

Лучшей моделью по validation стала **HistGradientBoosting без L2-регуляризации**. На отложенной test-выборке из 423 объектов она получила:

- Accuracy — **0.9716**;
- F1 macro — **0.9713**;
- ROC-AUC OvR macro — **0.9980**;
